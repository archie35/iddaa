# IDDAA AI Predictor

JavaScript/Node.js tabanlı bülten analiz uygulaması.

## Çalıştırma
npm install
npm start

## Gerçek veri API\n.env içinde BULLETIN_API_URL ve gerekiyorsa BULLETIN_API_KEY tanımlanır. Yanıt dizi veya matches/events/data alanlarından biri olabilir.

Demo verisi içerir. Model garanti vermez; gerçek bülten için izinli/lisanslı veri API gerekir.
